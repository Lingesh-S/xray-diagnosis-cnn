# Progress Report — 2026-11-09

## Summary
Phase 3 (Web App & CI) was merged into `main` via PR #3 with CI green. Phase 4 (real training,
results and documentation) is complete on `feature/docs-results` and ready for review.

## Done
- **Data** — downloaded the Kaggle dataset (5,856 images); split 4,708 train / 524 val / 624 test.
- **Stage 1 training** — MobileNetV2 with a frozen backbone, 20 epochs (~1 h on CPU).
  Test: 83.8% accuracy, 99.0% recall, 58.5% specificity, AUC 0.967.
- **Threshold tuning** — `python -m lungai.evaluate --tune-threshold` picks the threshold on the
  validation split (Youden's J) and saves it next to the model. Stage 1 at 0.72: 87.0% accuracy.
- **Stage 2 fine-tuning** — new `--init-from`, `--fine-tune-layers`, `--learning-rate` and
  `--run-name` training options; last 40 layers unfrozen at lr 1e-5, 10 epochs (~15 min).
- **Final test results** (threshold 0.81): **89.1% accuracy, 98.7% recall, 73.1% specificity,
  85.9% precision, F1 0.919, AUC 0.974**.
- **App** — preselects the newest model and starts from its tuned threshold.
- **Docs** — README rewritten (setup, training, evaluation, app, results, screenshots, CI badge);
  model card added (`docs/model_card.md`).
- **Tests** — 30 passing (4 new: threshold selection, threshold save/load, fine-tuning from a saved
  model, app default threshold).

## Goal check
- G3 (transfer model ≥ 90% accuracy, ≥ 95% recall): recall met; accuracy 89.1%, just short.
  The threshold was not tuned on the test set to close the gap.
- G2 (custom CNN baseline ≥ 85%): the baseline exists and is tested but has not been trained on
  the real data yet.

# Progress Report — 2026-10-24

## Summary
Phase 1 (Foundation) was merged into `main` via PR #1. Phase 2 (Evaluation &
Explainability) is implemented on `feature/evaluation-gradcam` and ready for review.

## Done
- **Evaluation** (`python -m lungai.evaluate`) — runs the saved model on the test split and writes
  `reports/metrics.json` (accuracy, precision, recall, specificity, F1, ROC-AUC, confusion matrix),
  `confusion_matrix.png` and `roc_curve.png`. Decision threshold is configurable (`--threshold`).
- **Grad-CAM** (`lungai.gradcam`) — heatmaps for all three models (custom CNN, MobileNetV2,
  EfficientNetB0); explains whichever class was predicted; colour overlay on the original image.
- **Prediction CLI** (`python -m lungai.predict image.jpeg --gradcam out.png`) — label, confidence
  and an optional heatmap overlay.
- **Tests** — 23 passing (9 new: metric values, report files, Grad-CAM for every model, predict + overlay).
- End-to-end check on a synthetic dataset: train → save → reload → evaluate → predict + Grad-CAM all work.

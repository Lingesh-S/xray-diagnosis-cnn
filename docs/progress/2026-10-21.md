# Progress Report — 2026-10-21 (Day 1)

## Summary
Project kicked off. The repo previously had only a README and LICENSE. Phase 1
(Foundation) code is written and pushed on the `feature/project-foundation` branch;
it will be merged into `main` via pull request once approved.

## Done
- **GOALS.md** — problem statement, 8 measurable goals, dataset notes, architecture, 4-phase roadmap.
- **Project layout** — `src/lungai` package, `configs/config.yaml`, `requirements.txt`, `pyproject.toml`, `.gitignore`.
- **Data pipeline** (`lungai.data`) — image discovery, pooled + stratified train/val re-split
  (the official val split has only 16 images), balanced class weights, `tf.data` loader with light augmentation.
- **Models** (`lungai.model`) — custom 4-block CNN baseline, MobileNetV2 and EfficientNetB0 transfer models;
  all take raw [0, 255] RGB and output P(PNEUMONIA).
- **Training** (`python -m lungai.train`) — Adam, BCE loss, accuracy/precision/recall/AUC,
  checkpointing, early stopping, LR schedule, CSV history.
- **Dataset helper** — `scripts/download_data.py` (Kaggle via `kagglehub`).
- **Tests** — pytest suite on a synthetic dataset (data, models, 1-epoch training smoke test).
